Recall запоминает всё, что вы копируете, позволяет искать это по *смыслу*, а не по точным словам,
и обращается со всем, что похоже на учётные данные, как с радиоактивным материалом.

![Панель истории Recall: поиск «rounding» находит CSS-фрагмент с border-radius, в котором этого слова нет](docs/demo.gif)

Поиск **rounding** находит фрагмент с `border-radius` — слова, которого в нём нет. Никакого
словаря синонимов и никакого облака: модель эмбеддингов на устройстве и расширитель запросов,
который работает на вашем Mac.

## Зачем ещё один менеджер буфера обмена

Потому что интересные задачи в менеджере буфера обмена — это не хранение и не список. Вот они:

- **Вы помните, *чем* была вещь, а не *что в ней было написано*.** Значит, поиск должен работать
  по смыслу.
- **Менеджер буфера обмена — самый удобно расположенный похититель учётных данных на машине.**
  Значит, его нужно строить так, будто он им и является, — и отказаться.
- **Модель должна работать там же, где данные.** Отправлять буфер обмена в API ради краткого
  пересказа — странная цена за одно предложение.

Всё, что ниже, следует из этих трёх пунктов.

---

## Поиск, достойный этого слова

Введите то, что помните наполовину. Recall сравнивает эмбеддинг вашего запроса, посчитанный на
устройстве, с каждым фрагментом — после того как грубый фильтр сужает круг, чтобы перебор
оставался реальным по мере роста истории.

Благодаря расширению запроса и работает демо выше: одни только эмбеддинги предложений ставят
CSS-правило по запросу *«rounding»* ниже не связанного с ним кода. Языковая модель на устройстве
сначала расширяет запрос. Это измерено, а не предположено: есть стенд для оценки ранжирования с
запросами, которые человек набрал бы на самом деле, он считает recall@3 — и в день, когда его
написали, он поймал настоящую регрессию.

Операторы сочетаются со всем этим:

| Оператор | Находит |
| --- | --- |
| `kind:image` | только изображения — также `text`, `link`, `color`, `file` |
| `app:Xcode` | фрагменты, скопированные из конкретного приложения |
| `since:yesterday` | всё, что новее |
| `is:pinned` | ваши закреплённые фрагменты |

**Умные коллекции** — это сохранённые вопросы. Их наполняют автотеги, а ещё можно написать
собственные правила. Очистка истории не удаляет коллекцию — вопрос переживает свои ответы.
Коллекция без условий отклоняется, а не молча совпадает со всем подряд.

## Вставить как…

Нажмите **⌥⏎** на любом фрагменте, чтобы пропустить его через модель на устройстве перед вставкой:
таблица Markdown, перевод, краткий пересказ, JSON, Python.

Результат появляется в предпросмотре по мере генерации, и ничего не вставляется, пока вы его не
примете. Преобразование — это *догадка* о намерении, а вставить догадку в чужой документ — верный
способ потерять доверие.

Для фрагмента, помеченного как секрет, нет ни преобразований, ни раскрытия, ни меню ИИ.

## С секретами обращаются как с радиоактивным материалом

Менеджер буфера обмена видит каждый пароль, который вы копируете. Recall построен на
предположении, что это риск, а не функция.

### Распознаются при копировании

**29 правил** срабатывают в момент копирования, до того как что-либо будет записано. Каждое — это
опубликованный фиксированный формат, поэтому ложных срабатываний почти не бывает:

| | |
| --- | --- |
| **Облака и инфраструктура** | Ключ доступа AWS, секретный ключ AWS, ключ API Google, токен Cloudflare, конфигурация Kubernetes |
| **Платформы разработки** | Токен GitHub, токен GitLab, токен npm, токен Hugging Face |
| **Платежи и связь** | Ключ Stripe, идентификатор Twilio, ключ SendGrid, токен Slack, токен бота Discord, токен бота Telegram |
| **Поставщики ИИ** | Ключ API Anthropic, универсальные ключи API `sk-` / `pk-` |
| **Ключи и токены** | Блок закрытого ключа, веб-токен JSON |
| **Личные данные** | Номер карты, IBAN, номер удостоверения личности, фраза восстановления, пароль для приложения |
| **Текстовые шаблоны** | URL с паролем, строка подключения к базе данных, файл окружения, присваивание пароля, одноразовый код |

Совпавший фрагмент помечается как `secret`. Он **хранится только в памяти и никогда не
записывается на диск**, скрыт в списке, исключён из функций ИИ и **удаляется через 60 секунд**
(настраивается).

Recall также сообщает, *какое* правило сработало. Предупреждение, которое нельзя проверить, —
это предупреждение, которое учишься игнорировать. Любое правило можно отключить по отдельности.

### Не записываются вовсе

Фрагменты из **28 менеджеров паролей и аутентификаторов** — 1Password, Bitwarden, KeePassXC,
Dashlane, Enpass, LastPass, NordPass, Proton Pass, Strongbox, Secretive, «Связка ключей» и
«Пароли» от Apple, Authy и других — отбрасываются ещё до чтения, как и элементы буфера обмена,
которые записавшее их приложение пометило как скрытые. Можно добавить и свои приложения.

### Режим «Только в памяти»

Запустите всё приложение в оперативной памяти. Ни файла базы данных, ни каталога с данными, ни
ключа шифрования. Выход из приложения стирает всё.

### На диске

Всё остальное — в зашифрованной базе SQLite: содержимое, запечатанное AES-GCM, слепые индексы для
поиска, журнал WAL, права `0700` на каталог.

## Коды двухфакторной аутентификации

Recall генерирует коды TOTP и HOTP — те самые шесть цифр, которые даёт приложение-аутентификатор.
Нажмите **⌘⇧A**.

У этой функции больше всего причин *не* существовать в менеджере буфера обмена, поэтому она
построена по другим стандартам, чем остальное приложение.

### Секреты хранятся не в приложении

Секрет 2FA — это не пароль. Он бесконечно выпускает действительные коды и никогда не меняется сам.
Поэтому Recall его не хранит.

Секреты живут в **отдельном изолированном (sandboxed) вспомогательном процессе XPC** со своей
подписью кода, своим контейнером и своими — гораздо более узкими — правами. Основное приложение не
может работать в песочнице (для чтения приложения-источника буфера обмена и имитации ⌘V нужны
возможности, которых песочница не даёт), но **помощник — может**, и он отказывается от всего, что
ему не нужно: никакой сети, файлов, Универсального доступа, буфера обмена и камеры.

В протоколе между ними нет ни одного вызова, который возвращал бы секрет. Ни защищённого, ни
требующего аутентификации — такого метода просто нет, потому что приложению незачем хранить
секрет. Оно просит *код* и получает *код*.

Секреты запечатываются AES-GCM в контейнере помощника, с правами `0600`, в одном документе,
который перезаписывается атомарно, так что наполовину записанный набор невозможен.

> **Почему не Связка ключей?** Это был очевидный вариант, но он не работает без платной подписи.
> Связка ключей с защитой данных решает вопрос доступа по entitlement, для которого нужен
> настоящий идентификатор команды, а у ad-hoc-сборки его нет — она отвечает
> `errSecMissingEntitlement`. Файловая связка ключей решает доступ через ACL, привязанный к
> подписи вызывающего кода, которая меняется с каждой сборкой, поэтому она пытается *спросить
> пользователя* — а у сервиса XPC нет интерфейса, чтобы спросить, и всё заканчивается
> `errSecInteractionNotAllowed`. Запечатанный контейнер слабее записи в связке ключей с защитой
> данных и гораздо надёжнее открытого текста — и это лучшее, что доступно без Developer ID.
> См. [ADR 0005](docs/adr/0005-two-factor-helper.md).

### Touch ID по умолчанию

Аутентификация **по умолчанию обязательна**: настройка безопасности, которую приложение может
переключить само, — не настройка по умолчанию. Три политики:

- **Всегда** — каждый код, каждый раз.
- **После паузы** — 1, 5, 15, 30 или 60 минут. Отсчёт хранится только в памяти, так что выход из
  Recall или перезапуск помощника начинают следующий код с блокировки. Пауза, пережившая
  перезапуск, — это пауза, которую никто не выбирал.
- **Никогда** — любой, кто сидит за клавиатурой, может прочитать любой код.

Выбор хранится в помощнике, а не в настройках Recall.

### Добавление учётной записи

- **Отсканируйте QR-код с экрана.** Выделите область с QR-кодом регистрации — и Recall прочитает
  его. Никакого телефона — это самый быстрый путь.
- **Скопируйте ссылку `otpauth://`** — и Recall предложит импортировать её, вместо того чтобы
  сохранить фрагмент, бесконечно выпускающий коды. Ссылки `otpauth-migration://`, экспортированные
  из Google Authenticator, тоже работают, включая несколько учётных записей сразу.
- **Введите секрет вручную** — для сайтов, которые показывают только base32.

### Использование кода

Коды показываются вместе с оставшимися секундами. Скопируйте код или вставьте его прямо в
приложение, в котором вы были. Коды хранятся, только пока действительны, и стираются из памяти при
закрытии панели.

### Единственное, чего он не сделает

Recall **не может** раскрыть сокращение или автоматически вставить текст в поле пароля — и не
пытается. macOS включает там **Secure Event Input**, который блокирует перехватчик событий
сеанса, который слушает Recall. Это операционная система защищает вас ровно от того класса
программ, к которому относится Recall, и обойти это нельзя — и не нужно.

## Сниппеты и сокращения

Назначьте фрагменту сокращение — `:sig`, `:addr` — и его ввод в любом месте раскроет фрагмент.
Перехватчик событий, который только слушает, ждёт сокращение, затем стирает его и вставляет
сниппет, после чего восстанавливает то, что было в буфере обмена.

При закреплении фрагмента Recall предлагает назначить сокращение — ненавязчивой ссылкой, а не
окном, которое прерывает закрепление.

## Текст из картинок

**⌘⇧⌥2** выделяет область экрана, Vision читает её, и текст попадает и в буфер обмена, *и* в
историю. Под капотом — `screencapture`, поэтому интерфейс выделения вам уже знаком, а запрос
разрешения — системный.

Скопированные изображения распознаются в фоне, и найденный текст полностью доступен для поиска —
так что снимок экрана с сообщением об ошибке находится по самой ошибке.

Язык определяется автоматически, а не зашит как английский.

## Всё остальное

- **Каждый формат показывается таким, какой он есть** — текст, RTF, изображения, файлы, ссылки и
  шестнадцатеричные цвета. Ссылки дополняются заголовком и значком; цвета показывают образец.
- **Закреплённые** — та часть истории, которую вы отбираете сами. Закреплённый фрагмент *никогда*
  не удаляется автоматически: ни лимитом истории, ни сроком хранения, ни истечением секретов. Там,
  где Recall удалил бы что-то, он вместо этого предупреждает.
- **Сравнение двух фрагментов** — ⌘D на одном, ⌘D на другом, и вы получаете различия по строкам
  или словам. Удобно для двух версий конфигурации или переписанного абзаца.
- **Быстрый просмотр** — ⌘Y, настоящая панель предпросмотра.
- **Очередь вставки** — собирайте фрагменты через ⌘⌥⌃C и вставляйте их по порядку.
- **Краткие пересказы** длинных фрагментов — с видимым состоянием «Чтение…», а не строкой, которая
  молча переписывает себя.
- **Автотеги** от модели на устройстве, которые наполняют умные коллекции.
- **Приложение в строке меню** — без значка в Dock. Вызвали, воспользовались, оно исчезло.
- **На вашем языке** — английский, персидский (с полной поддержкой письма справа налево), русский
  и упрощённый китайский. Recall следует языку системы, или выберите язык только для него в
  **Системных настройках › Основные › Язык и регион**.

## Что никогда не покидает ваш Mac

Каждый эмбеддинг, каждый пересказ, каждый тег и каждое преобразование выполняются на устройстве.
Нет ни учётной записи, ни телеметрии, ни аналитики, ни синхронизации.

Единственное исключение — **обогащение ссылок**: для скопированного URL загружаются заголовок и
значок. Это запрос к самому сайту, и больше никуда. Его можно полностью отключить в настройках, и
эта настройка действительно отключает обогащение, а не служит украшением.

## Установка

**Соберите из исходников.** Это одна команда, и это поддерживаемый путь:

```bash
git clone https://github.com/cnazk/recall-mac.git
cd recall-mac
./Scripts/install.sh --build
```

Нужна macOS 26 или новее. Никаких сторонних зависимостей.

Старый бандл *удаляется*, а не перезаписывается: копирование поверх рабочего бандла оставляет
устаревшие файлы, и этот проект уже терял дни на ошибках упаковки, которых не видит ни один
модульный тест.

```bash
make test   # все тесты
make app    # собрать и подписать .build/Recall.app
make run    # собрать и запустить
```

> **Почему нет готовой загрузки?** Recall подписан ad-hoc, а не Developer ID, потому что у проекта
> пока нет членства в Apple Developer Program. Gatekeeper отклоняет загруженную сборку, а обычный
> обходной путь — просить вас вручную снять атрибут карантина — плохая привычка для приложения,
> которое читает буфер обмена и просит Универсальный доступ. К тому же ad-hoc-подпись привязана к
> хешу сборки, поэтому macOS считает каждый выпуск другим приложением и сбрасывает разрешение
> Универсального доступа при каждом обновлении. Подпись Developer ID решает обе проблемы, и это
> следующий этап выпуска.

Этапы 1–6 готовы: надёжная запись, панель, поиск, функции ИИ, извлечение и рабочие процессы,
одноразовые коды и шлифовка. Этап 7 — выпуск — в работе.

### Известные ограничения

Названы сразу, вместе с тем, что будет дальше. Два из них исправляются; исправить ещё два — не в
наших силах, и сказать это честно полезнее, чем дать обещание, которое не сбудется.

| Ограничение | Статус |
| --- | --- |
| **Пока нет загрузки** — сборки подписаны ad-hoc, и Gatekeeper их отклоняет | **Исправляется.** Подпись Developer ID и нотаризация — следующий этап выпуска; конвейер выпуска уже готов и ждёт сертификата. |
| **Разрешение Универсального доступа теряется при каждом обновлении** — ad-hoc-подпись привязана к хешу сборки, и macOS видит в каждой сборке другое приложение | **Исправится тем же изменением.** Подпись Developer ID стабильна между версиями, и разрешение сохраняется. |
| **Нет OCR для персидского** — в Vision на macOS нет распознавателя `fa` | **Не в наших силах.** Автоопределение языка включено, а *поиск* по арабской письменности нормализуется, так что вставленный персидский текст находится. Распознавание ждёт Apple. |
| **Сокращения не раскрываются в полях паролей** | **Так и задумано.** macOS включает там Secure Event Input, который блокирует перехватчик событий, используемый Recall. Это ОС защищает вас ровно от того класса программ, к которому относится Recall, и Recall не станет это обходить. |

## Поддержать Recall

Recall бесплатен и открыт, и таким останется. Само приложение никогда не просит денег: в нём нет
ни кнопки пожертвования, ни напоминаний, ни навязчивых сообщений — ничто не встаёт между вами и
буфером обмена. Если Recall вам полезен и вы хотите поддержать его развитие, это можно сделать
здесь.

**Coffee Bede** — с иранской банковской картой: [coffeebede.com/cnazk](https://www.coffeebede.com/cnazk)

**Криптовалюта** — копируйте адрес, а не перепечатывайте его, и отправляйте только в той сети,
